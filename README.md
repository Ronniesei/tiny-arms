# Tiny Arms

Co-op dino survival in your browser for 1-4 mates: survive 20 waves as a cute T-Rex with tiny arms,
collect amber, shop between waves, and beat the Triceratops.

**Play:** https://ronniesei.github.io/tiny-arms/

Host a game, copy the invite link, and send it to your mates. See HOW-TO-PLAY.md for controls.
Built with Phaser and PeerJS; see CREDITS.md.
